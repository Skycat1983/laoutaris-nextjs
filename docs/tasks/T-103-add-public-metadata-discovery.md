## Goal

Replace scaffolded app metadata and add baseline crawler discovery files for
the public Joseph Laoutaris archive without changing route rendering, checkout,
or policy-page scope.

## Context

- A-010 found root metadata still used scaffolded Next app title and
  description text.
- A-010 found no `sitemap`, `robots`, canonical/social metadata, or structured
  data files beyond the favicon.
- T-102 removed global public-shell auth/database blockers; metadata and
  discovery are the next owner-independent A-010 follow-up.
- The app is a public archive and early enquiry-based shop for Joseph
  Laoutaris artwork. Avoid claims about checkout, payments, policies, shipping,
  refunds, or guarantees in metadata.

## Scope

- In scope:
  - Replace root metadata with production-safe archive title/description and
    basic Open Graph/Twitter metadata using existing public app facts.
  - Add `metadataBase` from a safe app URL helper or conservative environment
    handling without exposing secrets.
  - Add `src/app/robots.ts` with production-safe crawl rules.
  - Add `src/app/sitemap.ts` for stable public top-level routes and any
    route entries that can be generated without introducing new live-service
    coupling beyond existing route-local data behavior.
  - Add focused static tests for root metadata text, robots output, sitemap
    routes, and absence of scaffold metadata.
  - Update this task brief and relevant workstreams after completion.
- Out of scope:
  - Full route-specific `generateMetadata()` for every artwork, article, blog,
    collection, and product detail page.
  - JSON-LD/structured data for artwork, products, articles, blogs, or
    breadcrumbs.
  - Owner/legal policy pages, privacy/terms/cookie notices, or commerce
    assurance copy.
  - Checkout/cart, Shopify product availability, or sale terms.
  - Route cache/ISR policy beyond what metadata/sitemap require.
