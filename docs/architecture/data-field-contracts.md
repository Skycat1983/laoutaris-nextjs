# Data Field Contracts

Status: Active contract matrix for the F-039 implementation backlog.

This document records the authoritative contract decisions for the known
article, blog, and user field drift found by
[A-003](../audits/results/A-003-data-models-transforms.md). It is intentionally
small: it covers only the fields needed to unblock the next implementation
slices and does not change runtime behavior by itself.

## Contract Principles

- Mongoose remains the persistence gate, but route schemas should reject invalid
  admin/user input before model writes.
- TypeScript persisted types should match valid stored documents, including
  fields that are optional because of OAuth or model defaults.
- Public and admin DTOs should preserve existing UI behavior unless a field is
  unsafe or impossible to persist correctly.
- Shared constants should be the source of truth for enums used by models,
  schemas, and UI option lists.
